# 段码屏循环点亮 · 八个小灯

一个纯 HTML/CSS/JS 实现的“段码屏”小灯演示页面。

## 功能

- **循环点亮**：8 个小灯围绕圆心循环跑动，模拟段码屏循环点亮效果。
- **输入数字点亮**：在输入框输入 `1–8` 的数字（回车或点击“点亮”），对应位置的小灯会点亮 **1 秒**，随后自动恢复循环。
- **恢复循环**：点击“恢复循环”按钮可随时回到循环点亮状态。

## 使用方式

直接双击打开 `index.html`，或用任意浏览器打开即可，无需任何依赖。
