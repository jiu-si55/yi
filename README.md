# 段码屏 · 八个小灯

一个纯 HTML/CSS/JS 实现的“段码屏”小灯演示页面。

## 功能

- **八个小灯**：1–8 号 LED 灯围绕圆心均匀分布。
- **点击点亮**：点击任意数字按钮（1–8），或直接点击对应的小灯本身，该小灯亮起（黄色光效）。
- **切换/熄灭**：点击其它数字会切换到对应小灯；再次点击已点亮的小灯会熄灭它。
- **全部熄灭**：点击“全部熄灭”按钮可一次关闭所有小灯。

## 使用方式

直接双击打开 `index.html`，或用任意浏览器打开即可，无需任何依赖。
