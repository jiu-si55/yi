# 七段码屏 · 八个小灯

一个纯 HTML/CSS/JS 实现的七段数码管 + 一排小灯演示页面。

## 功能

- **七段码屏**：输入数字 `1–8`，七段数码管显示对应数字（红色光效）。
- **一排八个小灯**：1–8 号小灯横向排列。
- **同步点亮 2 秒**：输入数字后，七段码屏显示该数字的同时，对应位置的小灯也点亮，2 秒后一起熄灭。
- **输入方式**：在输入框输入数字后回车或点“显示”，也可直接点击数字按钮 1–8。

## 使用方式

直接双击打开 `index.html`，或用任意浏览器打开即可，无需任何依赖。
